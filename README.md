# ⏱️ Uptime Widget — เปิดคอมมานานแค่ไหนแล้ว?

ตัวจับเวลาเล็กๆ บนหน้าจอ บอกว่า **เปิดคอมมาแล้วกี่ชั่วโมง** อัปเดตทุกวินาที
หน้าตาเป็นการ์ดสีเข้มมุมโค้ง ไม่มีกรอบหน้าต่าง กินทรัพยากรน้อย และ **ไม่กวนตอนเล่นเกม**

![AutoHotkey](https://img.shields.io/badge/AutoHotkey-v2-3A7D44?logo=autohotkey&logoColor=white)
![Python](https://img.shields.io/badge/Python-3-3776AB?logo=python&logoColor=white)
![Platform](https://img.shields.io/badge/Windows-10%20%7C%2011-0078D4?logo=windows&logoColor=white)

> *A tiny, borderless desktop widget that shows how long your PC has been on. Resets properly after shutdown, stays out of your way while gaming.*

## ✨ ฟีเจอร์ของ `uptime.ahk`

### 🕐 นับเวลาแม่นยำ
- แสดงเป็น `ชั่วโมง:นาที:วินาที` และมี `N วัน` ขึ้นมุมขวาบนเมื่อเปิดนานเกิน 1 วัน
- **กด Shutdown แล้วเปิดใหม่ เลขจะเริ่มจาก 00:00:00** (ดูหัวข้อ [วิธีการทำงาน](#-วิธีการทำงาน))

### 🎨 สีและข้อความตามความนาน
| เวลาที่เปิด | สีตัวเลข | ข้อความ |
|------------|:-------:|---------|
| ต่ำกว่า 1 ชม. | 🟢 เขียว | เพิ่งเริ่มต้น สู้ๆ นะ |
| 1 – 2 ชม. | 🟢 เขียว | ครบ 1 ชั่วโมงแล้ว ดื่มน้ำสักแก้วไหม |
| 2 – 4 ชม. | 🟡 เหลือง | นั่งมาสักพักแล้ว ลุกยืดเส้นหน่อยนะ |
| 4 – 8 ชม. | 🟠 ส้ม | ทำงานมานานมาก พักสายตา 5 นาทีนะ |
| 8 ชม. ขึ้นไป | 🔴 แดง | เกิน 8 ชั่วโมงแล้ว! ไปพักผ่อนบ้างนะ |

### 🏆 สถิติเปิดนานสุด
เก็บสถิติไว้ข้ามวัน ถ้ารอบนี้นานกว่าสถิติเดิมจะขึ้น **"★ กำลังทำสถิติใหม่!"** ถ้ายังไม่ถึงจะโชว์สถิติเดิมให้ดู

### 🎮 ไม่กวนตอนเล่นเกม
- **ไม่ลอยบนสุดโดยปริยาย** อยู่ชั้นเดียวกับหน้าต่างทั่วไป พอเข้าเกมก็โดนบังเอง
- **ซ่อนอัตโนมัติ** เมื่อมีโปรแกรมเต็มจอ (เกม, วิดีโอเต็มจอ, F11 ในเบราว์เซอร์) ออกจากเต็มจอแล้วกลับมาเอง
- **ไม่แย่งโฟกัส** คลิกโดนตัวจับเวลาก็ไม่ทำให้เกมหลุดโฟกัส
- **โปร่งใสเล็กน้อย** ปรับความทึบได้
- **คลิกทะลุ** (เปิดได้จากเมนู) ให้เมาส์ทะลุผ่านตัวจับเวลาไปโดนหน้าต่างข้างหลัง

## 🚀 วิธีติดตั้งและใช้งาน

### เวอร์ชัน AutoHotkey (`uptime.ahk`)

1. ติดตั้ง **AutoHotkey v2** จาก [autohotkey.com](https://www.autohotkey.com/) (ต้องเป็น **v2** เท่านั้น v1 รันไม่ได้)
2. ดาวน์โหลดไฟล์ `uptime.ahk` (หรือกด **Code → Download ZIP** ที่หน้า repo นี้)
3. ดับเบิลคลิก `uptime.ahk` ตัวจับเวลาจะขึ้นมุมขวาบนของหน้าจอ

### เวอร์ชัน Python (`uptime.pyw`)

1. ติดตั้ง **Python 3** จาก [python.org](https://www.python.org/downloads/) (ตอนติดตั้งให้ติ๊ก *Add python.exe to PATH*)
2. ดับเบิลคลิก `uptime.pyw` (นามสกุล `.pyw` ทำให้ไม่มีหน้าต่าง cmd โผล่มา)
3. ถ้าดับเบิลคลิกแล้วไม่ขึ้น ให้เปิด Command Prompt ในโฟลเดอร์ แล้วพิมพ์ `python uptime.pyw`

### ให้เปิดเองทุกครั้งที่เปิดคอม

1. กด `Win + R` พิมพ์ `shell:startup` แล้วกด Enter
2. คลิกขวาที่ไฟล์ `uptime.ahk` (หรือ `uptime.pyw`) → **Create shortcut** แล้วลากทางลัดไปวางในโฟลเดอร์ที่เปิดขึ้นมา

### อยากได้เป็นไฟล์ `.exe` (ไม่ต้องลง AutoHotkey ในเครื่องอื่น)

คลิกขวาที่ `uptime.ahk` → **Compile script** (มากับตัวติดตั้ง AutoHotkey v2) จะได้ `uptime.exe` ที่เปิดใช้ได้ทันที

## 🕹️ วิธีควบคุม (เวอร์ชัน AHK)

### ปุ่มลัด

| ปุ่ม | ทำอะไร |
|------|--------|
| `Ctrl + Alt + U` | แวบขึ้นมาดูเวลาบนสุด 4 วินาที แล้วกลับไปอยู่เบื้องหลัง (ใช้ได้แม้ตอนเล่นเกมแบบ Borderless) |

### เมาส์

| การกระทำ | ผลลัพธ์ |
|----------|---------|
| ลากที่ตัวการ์ด | ย้ายตำแหน่ง (จำไว้ให้ครั้งต่อไป) |
| คลิก **✕** | ปิดโปรแกรม |
| คลิกขวาที่การ์ด | เปิดเมนู |
| คลิกที่ไอคอนถาดระบบ | แวบดูเวลา |
| คลิกขวาที่ไอคอนถาดระบบ | เปิดเมนูเดียวกัน |

### เมนู

- **ดูเวลา (Ctrl+Alt+U)** แวบขึ้นมาชั่วคราว
- **ซ่อนตัวจับเวลา** ซ่อนถาวรจนกว่าจะกดอีกครั้ง
- **ลอยบนสุดเสมอ** บังคับให้อยู่เหนือหน้าต่างอื่นทั้งหมด (ปิดไว้โดยปริยาย)
- **คลิกทะลุ** ให้เมาส์ทะลุผ่านการ์ด (ถ้าเปิดไว้ จะลากหรือกด ✕ ไม่ได้ ให้ใช้เมนูที่ไอคอนถาดระบบแทน)
- **ปิดโปรแกรม**

## ⚙️ ปรับแต่ง

เปิด `uptime.ahk` ด้วย Notepad แล้วแก้ค่าที่ด้านบนสุดของไฟล์

| ค่า | ความหมาย | ค่าเริ่มต้น |
|-----|----------|:-----------:|
| `OPACITY` | ความทึบของการ์ด 0–255 (น้อย = โปร่งมาก) | `215` |
| `PEEK_MS` | เวลาที่แวบโชว์เมื่อกด Ctrl+Alt+U (มิลลิวินาที) | `4000` |

อยากเปลี่ยนข้อความ สี หรือเกณฑ์ชั่วโมง ดูในฟังก์ชัน `Tick()` ท้ายไฟล์ (ตัวแปร `colors` และบล็อก `if (hrs >= ...)`)

## 🔧 วิธีการทำงาน

**ทำไมกด Shutdown แล้วเลขไม่รีเซ็ต?**
Windows 10/11 เปิด *Fast Startup* ไว้โดยปริยาย ตอนกด Shutdown เครื่องไม่ได้ดับเต็มที่ แต่เก็บสถานะแล้วหลับลึก (hibernate) ตัวนับเวลาของระบบ (`GetTickCount64`) เลยนับต่อ เวอร์ชัน Python ที่อ่านค่านี้จึงไม่รีเซ็ต

**เวอร์ชัน AHK แก้ยังไง?**
การ Shutdown แบบ Fast Startup จะ *ล็อกเอาต์ผู้ใช้* ทุกครั้ง ทำให้ `explorer.exe` (ตัวที่คุมแถบงาน) เริ่มใหม่เมื่อล็อกอินรอบถัดไป โปรแกรมจึงอ่าน **เวลาเริ่มทำงานของโปรเซสแถบงาน** (`GetProcessTimes`) แล้วใช้เป็นจุดเริ่มนับ เมื่อเปิดคอมใหม่เลขก็เริ่มจากศูนย์

**ตรวจจับโปรแกรมเต็มจอยังไง?**
ทุกวินาทีโปรแกรมเช็กหน้าต่างที่กำลังใช้งาน ถ้า *ขนาดครอบคลุมทั้งจอ* และ *ไม่มีแถบหัวหน้าต่าง* ถือว่าเป็นโหมดเต็มจอ แล้วซ่อนการ์ดไว้จนกว่าจะออกจากโหมดนั้น

**ไม่แย่งโฟกัสยังไง?**
ตั้งสไตล์หน้าต่าง `WS_EX_NOACTIVATE` ทำให้คลิกการ์ดแล้วหน้าต่างอื่นไม่เสียโฟกัส

## 📁 ไฟล์ที่โปรแกรมสร้างในเครื่อง

| เวอร์ชัน | ไฟล์ | เก็บอะไร |
|----------|------|----------|
| AHK | `%APPDATA%\uptime_widget.ini` | ตำแหน่งการ์ด, สถิติเปิดนานสุด |
| Python | `~\.uptime_widget_pos` | ตำแหน่งการ์ด |

อยากรีเซ็ตตำแหน่งหรือสถิติ ให้ปิดโปรแกรมก่อน แล้วลบไฟล์เหล่านี้ทิ้ง

## ❓ แก้ปัญหาเบื้องต้น

<details>
<summary><b>ขึ้น error ว่าต้องใช้ AutoHotkey v2</b></summary>

ติดตั้ง AutoHotkey **v2** จาก autohotkey.com ถ้าในเครื่องมีทั้ง v1 และ v2 ให้คลิกขวาที่ `uptime.ahk` → **Open with** → เลือก v2
</details>

<details>
<summary><b>เปิดแล้วไม่เห็นตัวจับเวลา</b></summary>

ปกติจะไม่ลอยบนสุด อาจโดนหน้าต่างอื่นบังอยู่ ลองกด `Ctrl + Alt + U` หรือคลิกไอคอนที่ถาดระบบ ถ้ายังไม่เห็น ลองเช็กว่าไม่ได้กด "ซ่อนตัวจับเวลา" ไว้ในเมนู
</details>

<details>
<summary><b>ตัวจับเวลาโผล่ทับเกม</b></summary>

เกมบางตัวใช้หน้าต่างแบบที่ไม่ถือว่าเต็มจอ ลองเปลี่ยนเกมเป็นโหมด Borderless / Fullscreen หรือปิดตัวเลือก "ลอยบนสุดเสมอ" ในเมนู ถ้ายังโผล่ แจ้งชื่อเกมและโหมดหน้าจอมาที่ Issues ได้
</details>

<details>
<summary><b>กด Ctrl+Alt+U แล้วไม่ขึ้นในเกม</b></summary>

เกมแบบ Exclusive Fullscreen (เต็มจอจริง) จะไม่ยอมให้หน้าต่างอื่นแสดงทับ ลองเปลี่ยนเกมเป็นโหมด Borderless
</details>

<details>
<summary><b>เวลาไม่ตรงกับที่คิด</b></summary>

- ช่วงที่เครื่องหลับ (Sleep) ถูกนับรวมด้วย
- ถ้าแถบงาน (explorer.exe) ถูกรีสตาร์ตระหว่างที่โปรแกรมยังเปิดอยู่ ตัวนับจะไม่ถูกรีเซ็ต แต่ถ้ารีสตาร์ตก่อนเปิดโปรแกรม จุดเริ่มนับจะเป็นตอนที่ explorer เริ่มใหม่
</details>

## ⚠️ ข้อจำกัด

- ออกแบบมาสำหรับ **Windows 10/11** (เวอร์ชัน AHK ใช้ได้เฉพาะ Windows)
- เวอร์ชัน Python ยังอ่านเวลาเปิดเครื่องบน macOS/Linux ได้ แต่มุมโค้งโปร่งใสและฟอนต์ถูกปรับมาสำหรับ Windows
- เวอร์ชัน Python ไม่มีฟีเจอร์ซ่อนตอนเต็มจอและไม่รีเซ็ตเวลาหลัง Shutdown แบบ Fast Startup

## 🗑️ ถอนการติดตั้ง

1. ปิดโปรแกรม (กด ✕ หรือเมนูคลิกขวา → ปิดโปรแกรม)
2. ลบทางลัดออกจากโฟลเดอร์ `shell:startup` ถ้าเคยตั้งให้เปิดเอง
3. ลบไฟล์โปรแกรม และไฟล์ตั้งค่าตาม[ตารางด้านบน](#-ไฟล์ที่โปรแกรมสร้างในเครื่อง)
